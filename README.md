# 涂鸦鸡 · 草稿纸宠物

一只从草稿纸里蹦出来的涂鸦鸡，等你来照顾。

**形象完全按原图复刻**：圆滚滚的黑色铅笔线身体、两个圈圈触角、面条手臂和火柴腿。没有额外添加眼睛、嘴巴、腮红、配色或花纹，也没有把原图重绘成另一种风格。

## 运行

不需要安装任何依赖。

**推荐双击 `start-game.cmd`**。它会先把只读附件复制成游戏目录里的 `pet-original.jpg`，然后用默认浏览器打开 `index.html`；这样显示的就是原图本身。

也可以直接用浏览器打开 `index.html`。页面会按以下顺序找原图：

1. 浏览器里已经保存过的原图（`localStorage`）；
2. 游戏目录里的 `pet-original.jpg`；
3. 原始附件路径（`file:///C:/Users/Administrator/.dsh/attachments/...`）。

如果希望完全离线、或通过 `http://` 打开，也可以**单独双击一次 `copy-original.cmd`**，只复制 `pet-original.jpg` 而不打开游戏。之后游戏优先使用这个本地文件，刷新即可。

如果三种路径都不可用，画面会提示「原图未显示」，不会显示任何重绘版本；点一下提示（或玩法说明里的「载入原图」）选择原图文件即可。选一次后会存进浏览器，下次自动使用。

## 可以做什么

| 互动 | 操作 | 涂鸦鸡的反应 |
| --- | --- | --- |
| 喂食 | 点「喂食」，再从食物盘里挑一样 | 食物飞到身体上，咔嚓咔嚓嚼，掉碎屑；整只涂鸦鸡会开心地弹一下 |
| 洗澡 | 点「洗澡」，按住涂鸦鸡来回搓 | 冒泡泡、冒水珠，搓满后自动冲水、甩干、冒星星；身体图不会被涂改 |
| 摸摸 | 点「摸摸」，在它身上点按或划动 | 每摸一下冒一颗爱心；摸满五下会跳「草稿纸转圈舞」 |
| 玩耍 | 点「玩耍」，戳破五个泡泡 | 每戳破一个都会蹦一下；全部完成后撒纸屑、转圈 |
| 打盹 | 点右侧状态栏的「打个盹」 | 房间变暗，冒 zzz，精力慢慢恢复；睡醒后精神满满 |

数字键 `1`–`4` 也可以直接触发前四个互动；洗澡和摸摸时按 `空格` 或 `Enter` 也能操作。

## 状态与成长

- **饱腹 / 清洁 / 心情 / 精力** 会随时间缓慢下降，但涂鸦鸡不会生病，也不会离开。
- 每次照顾都会增加**亲密度**，亲密度升级会解锁新的关系称号，从「初次见面」一直到「命中注定的搭子」。
- 每天有一张**照顾清单**：喂食、洗澡、陪玩各一次。三项完成后会盖一个「今日达标」印章，额外获得亲密度。
- 进度保存在浏览器 `localStorage` 里，关掉页面再回来会继续。离开太久会补算一小段状态变化（最多两小时），不会有惩罚性结局。
- 右上角可以开关音效。所有音效都由 Web Audio 实时合成，没有音频文件。
- 右上角 `?` 里可以重新查看玩法、载入原图，或重新开始。

## 实现说明

- 纯 HTML / CSS / JavaScript，无第三方依赖、无外部字体。
- 角色叫**涂鸦鸡**。
- **角色本体只有一个来源**：原图 `<img>`。备用矢量图不再显示，不会用重绘版本替代原图。
- 原图会优先用 Canvas 处理成透明 PNG：白底和浅灰纸色全部去掉，只保留黑色/深灰线稿；如果浏览器因 `file://` 权限不让读像素，就用 SVG `removeWhite` 滤镜按亮度生成透明通道（并把浅灰阴影一起去掉），画面里同样只剩黑色线条。
- 动作全部作用在整张角色图上（弹跳、转圈、甩干、呼吸），开心时冒爱心和音符，不会改动原图本身。
- 喂食使用 Web Animations API 让食物飞过去；洗澡用指针移动距离累计搓洗进度，用泡沫 / 水滴粒子反馈。
- 响应式适配桌面和手机竖屏，支持键盘、触控和 `prefers-reduced-motion`。

## 文件

- `index.html` — 页面结构、房间场景、原图角色、食物和图标
- `styles.css` — 纸张 / 手绘视觉、布局、角色动画、响应式
- `game.js` — 状态机、存档、喂食 / 洗澡 / 摸摸 / 玩耍 / 打盹、音效和粒子
- `start-game.cmd` — 推荐：复制原图到 `pet-original.jpg` 并打开游戏
- `copy-original.cmd` — 可选：只复制 `pet-original.jpg`，不打开游戏
- `pet-original.jpg` — 运行上面任一脚本后生成的原图副本（当前尚未生成）
